# Riveting the left inboard top wing skin

<em>Hours: 5.0
Manual Ref: Page 16-3 steps 1, 2 &amp; 3
Partner: n/a</em>

As suggested in the plans (and Bill), back riveting is certainly the way to go for riveting the top skins. Unlike <a href="https://sites.google.com/a/fusion4.net/rv10/wings/leftwingmainsectioncomplete">Bill</a>, I didn't find it necessary to use an offset back riveter. I guess I was able to bend the ribs a little better than he could.
