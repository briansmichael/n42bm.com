# Paint Booth

<a href="http://www.brianmichael.org/media/rv10/2010/12_21_2010/PaintBooth.jpg"><img class="alignleft" style="margin: 5px;" src="http://www.brianmichael.org/media/rv10/2010/12_21_2010/PaintBooth_SM.jpg" alt="" width="200" height="135" /></a>Now that I'm at a point where I "have" to prime, I've been doing a lot of reading on how others have gone about the process.  Seeing as though it is currently well below the minimum 59 degrees Fahrenheit to be working with the primer, I'm building a setup to use in the garage.  For those familiar with Google's SketchUp, here is the <a href="http://www.brianmichael.org/media/rv10/2010/12_21_2010/PaintBooth.skp">PaintBooth.skp</a> file generated by the SketchUp application.  Or you can just see the 2D image on the left.  The reason for the different size boxes is due to the shape of my garage.  Overall, the size should about fill 1/2 of the garage, which I hope is big enough to handle those long spars or other large parts. I've about got it all built, and ready to start priming in the next day or two.
