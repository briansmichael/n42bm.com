# Continuing the “Class Project”

<a href="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0775.JPG"><img class="alignright" src="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0775_SM.JPG" alt="" width="200" height="150" /></a>Now the project is starting to move along.  As you can see, the clecos are brass in color.  That means I'm starting to use the 1/8th (a.k.a. AN470AD4-4) thick rivets.  It is definitely neat to see pieces start to go together.  It just makes it "look" like there is some progress being made.

<a href="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0776.JPG"><img class="alignleft" src="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0776_SM.JPG" alt="" width="200" height="150" /></a> Of course, there are always two sides to the spar, so here is a shot of the other side.  You can see the ribs under the spar.  I haven't gotten to those yet.

<a href="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0777.JPG"><img class="alignright" src="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0777_SM.JPG" alt="" width="150" height="200" /></a>

To the right you can see the full spar with both doublers cleco'd to it.  I still have some deburring to do.  The doublers (blue square pieces) have their holes pre-drilled, which does make the process a whole lot easier.

<a href="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0778.JPG"><img class="alignleft" src="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0778_SM.JPG" alt="" width="200" height="150" /></a> One the left I've added the ribs into the mix.  Still haven't riveted anything yet, but at least wanted to see what the thing looked like somewhat put together.  ...and I can definitely see how it is supposed to go together.  Now to figure out how to use that squeezer...

<a href="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0779.JPG"><img class="alignright" src="http://www.brianmichael.org/media/rv10/03_19_2010/IMG_0779_SM.JPG" alt="" width="150" height="200" /></a> Well, I figured out the squeezer.  All I can say is AN470AD4-4 rivets are hard to squeeze!  Even with the Cleaveland Tools squeezer (which is supposed to be easier to use), it was quite a challenge.  Time to do some more upper bod workouts at the gym.
